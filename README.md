# Hymns of Reformed Worship

A free, offline hymnal app for Android, with the 738 hymns of *Psalms & Hymns of Reformed Worship*.

**Download:** https://venson01.github.io/horw_mobile/

This repository only holds the download page (served by GitHub Pages) and the app files (under [Releases](https://github.com/venson01/horw_mobile/releases)). The hymn texts are used with the kind permission of the Metropolitan Tabernacle, London.

Found a problem? [Open an issue](https://github.com/venson01/horw_mobile/issues).
